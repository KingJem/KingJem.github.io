香橙派 5 Plus (Orange Pi 5 Plus) SD 卡刷机完整教程

本文最后更新于：2026年8月14日 下午

香橙派 5 Plus 用的是瑞芯微 RK3588（4×A76 + 4×A55，8nm，自带 6 TOPS NPU），跑 Linux 做小服务器、跑 Docker、跑云手机、跑本地模型都很合适。但它和树莓派不一样：RK3588 的启动介质有优先级，板子上可能同时存在 SPI Flash、eMMC、NVMe 和 SD 卡四个可启动位置，新手最常见的坑不是「卡没刷好」，而是「卡刷好了但板子没从卡启动」。

这篇按 SD 卡（TF 卡）方式，从选卡、选镜像、写卡到首次启动、扩容、排错，走一遍完整流程。

一、准备工作

硬件清单

项目 要求 说明
microSD 卡 ≥ 16GB，建议 32GB 起，A1/A2 + Class10/U3 桌面版镜像解包后就 10GB 左右，16GB 会很紧
读卡器 USB3.0 优先 劣质读卡器是写卡失败的头号原因
电源 5V/4A（或 PD 协议）Type-C 关键项，见下方说明
HDMI 线 + 显示器 可选 装 Server 版可以纯 SSH，不接显示器
网线 建议 首次启动用有线最省事

关于电源，多说一句，因为这是 RK3588 板子最容易踩的坑：用手机充电器或电脑 USB 口供电，大概率出现「能进系统但随机重启 / 跑满载就掉电 / SD 卡读写报错」。RK3588 满载 + NVMe + 外设的峰值电流不低，官方建议 5V/4A。很多被当成「SD 卡坏了」的问题，实际是供电不足。

关于「卡本身要好」这点，Ubuntu Rockchip 项目的 README 也专门强调过：启动或稳定性问题，多数情况来自电源不足，或者跟 SD 卡有关（坏卡、坏读卡器、烧写出错、卡太慢）。

顺手把卡测一下（强烈建议）

网购的「高速大容量卡」扩容卡比例不低，刷之前花几分钟测，比刷完排查两小时划算。

Windows 用 ValiDrive 或 H2testw；Linux / macOS 用 f3：

写入速度低于 10MB/s、或者读回校验报错，直接换卡，别犹豫。

二、选镜像：三个流派

香橙派 5 Plus 能刷的系统有三大类，用途差别很大，先选对再下载。

1. 官方镜像（orangepi.org）

官方提供 Orange Pi OS（Arch/Droid 系）、Ubuntu、Debian、Android 等，从官网产品页的「Download」进，网盘（Google Drive / 百度网盘）分发。

  • 优点：硬件支持最全，GPU/VPU/NPU、HDMI-in、2.5G 网口这些外设开箱可用；要用 NPU 跑 RKNN 模型，官方镜像基本是首选。
  • 缺点：基于 Rockchip 的 BSP 内核（5.10 系为主），内核较老，apt 源和内核更新节奏跟上游脱节。
  • 默认账号：官方镜像通常是 orangepi / orangepi，root / orangepi。首次登录务必改密码。

2. Ubuntu Rockchip（社区，推荐给多数人）

Joshua-Riek/ubuntu-rockchip 是社区把 Ubuntu 移植到 Rockchip 硬件的项目，对 Orange Pi 5 Plus 是一等支持，体验最接近「正常的 Ubuntu」。

写这篇时最新的 release 是 v2.4.0，Orange Pi 5 Plus 的镜像资产有这些（.img.xz，无需先解压）：

选哪个：

  • 做服务器 / 跑 Docker / 纯 SSH → server + 24.04（LTS，内核 6.1）
  • 要桌面、看视频、当轻办公机 → desktop + 24.04
  • 有老教程依赖 5.10 内核的驱动 → 22.04（Rockchip Linux 5.10）

项目特性里值得注意的几条：包管理走官方 Ubuntu 源、更新走 apt、panfork 提供 3D 加速、GNOME 跑在 Wayland 上、Chromium 可流畅播 4K。

默认账号：Server 版是 ubuntu / ubuntu（首次登录会要求改密码）；Desktop 版需要接 HDMI 走首次开机向导建账号。

下载页：Releases 或 专用下载站。

3. Armbian（社区，偏折腾/极简）

Armbian 的 Orange Pi 5 Plus 页面 提供 Debian/Ubuntu 多种组合，有 minimal/CLI 和桌面变体，内核分支也有多个可选。适合想要极简系统、或者习惯 armbian-config 那套工具链的人。首次登录用 root + 默认密码 1234，随后强制改密并创建普通用户。

我自己的取舍：要稳定跑服务，Ubuntu Rockchip Server 24.04；要用 NPU/多媒体硬件特性，官方镜像；要极简折腾，Armbian。

三、写卡

方式 A：balenaEtcher / USBImager（推荐，跨平台）

Ubuntu Rockchip 官方就推荐这两个，理由很实在：它们会在写完后做校验，不像某些工具写完就完事，让你拿着一张内容损坏的卡去排查启动问题。

balenaEtcher 步骤：

  1. Flash from file 选择 .img.xz（不用解压，Etcher 直接吃压缩包）
  2. Select target 选你的 SD 卡 —— 看清容量，别选错成移动硬盘
  3. Flash!，等写入 + 校验两个阶段都跑完
  4. 结束后 Windows 可能弹「需要格式化磁盘」，点取消。这是正常现象：Windows 认不出 Linux 的 ext4 分区

USBImager 更轻量（不到 300KB，无需安装），逻辑一样。

方式 C：Raspberry Pi Imager

能用，选 Use custom 加载本地镜像即可。但注意：不要用它的「预配置」功能（设置 WiFi/SSH/用户名那些），那套是给树莓派 OS 写 firstrun 逻辑的，对香橙派镜像无效，甚至可能干扰首次启动。

四、首次启动

插卡与启动优先级（最关键的一节）

microSD 卡槽在板子背面。插到底，一般会有轻微卡合感。

RK3588 的启动顺序大致是：SPI Flash（若烧了 bootloader）→ eMMC → NVMe → SD 卡。这意味着：

  • 板子是全新的、没有 eMMC 模块、SPI 空白 → 插卡直接就从卡启动，没有额外操作
  • 之前刷过 eMMC 或往 SPI 烧过 bootloader → 它会优先走那边，你的新卡看起来「刷了没反应」

如果遇到后者，按需处理：

  1. 物理拔掉 eMMC 模块，最直接

  2. 在已有系统里清掉 eMMC 引导头（认准设备名再执行，mmcblk* 编号在不同镜像下可能不同）：

  3. 清 SPI Flash：用 Rockchip 的 RKDevTool（Windows）或 rkdeveloptool，把板子按 MASKROM 键（板子上的小按钮，需上电前按住）连 USB-C 到电脑，进 maskrom 模式后擦除 SPI

接线开机

  1. HDMI 接显示器（Server 版可跳过）
  2. 网线插上
  3. 最后插电源

Ubuntu Rockchip 的 README 明确提示：首次启动可能需要长达两分钟，因为要做分区扩容、生成 SSH host key、初始化 first-run 向导。别看着黑屏就急着断电重插 —— 反复断电反而容易把文件系统搞坏。

板子上的指示灯是最好的判断依据：常亮/规律闪 = 在跑；完全不亮 = 检查供电和卡。

七、进阶：从 SD 卡迁到 NVMe

SD 卡当系统盘的随机读写和寿命都一般。跑真实服务建议先用 SD 卡把系统跑通，再迁到 NVMe（Orange Pi 5 Plus 有 M.2 M-Key 插槽，走 PCIe）。

大致思路是：SD 卡启动 → 装好系统 → 把根文件系统整体复制到 NVMe → 更新 bootloader 指向。官方镜像一般自带脚本，比如：

小结

SD 卡刷香橙派 5 Plus，本身只有三步：下对镜像 → 用带校验的工具写卡 → 插卡上电等两分钟。真正会卡住人的是三件事：

  1. 电源：5V/4A，不是手机充电器。大量「疑似坏卡」其实是供电问题
  2. 启动优先级：SPI/eMMC 会抢在 SD 卡之前，新板子无感，刷过的板子必踩
  3. 写卡校验：用 Etcher/USBImager 这种写完会校验的工具，省下的是后面几小时的盲猜
