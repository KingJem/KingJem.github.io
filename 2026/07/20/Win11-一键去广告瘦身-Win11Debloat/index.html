Win11 一键去广告瘦身：Win11Debloat 与那行 irm 命令

本文最后更新于：2026年8月14日 下午

前言

装完 Win11 一堆预装 app、开始菜单塞满推荐、搜索里混 Bing 结果、任务栏挂着 Widgets 和 Copilot、还有各种「建议」广告……手动一个个关又累又漏。

Win11Debloat（作者 Raphire，MIT 开源）把这些一次性收拾干净——移除预装 bloatware、关遥测、去 Bing/Copilot/Widgets、清理开始菜单和右键菜单、关各类广告推荐。Win10/Win11 都支持。

能清理什么

交互菜单里常见选项（可勾可不勾）：

  • 移除预装 app：Xbox 全家桶、Solitaire、Clipchamp、News、Weather、OneDrive、Teams（个人版）等（有「安全列表」和「全部」两档）；
  • 关闭遥测：Telemetry / 诊断数据 / 反馈；
  • 搜索去 Bing：任务栏搜索只搜本地，不再混网页结果；
  • 关 Copilot / Widgets / 聊天图标；
  • 清理开始菜单：移除推荐、固定项；
  • 右键菜单：恢复 Win10 经典右键（去掉「显示更多选项」那层）；
  • 关各类广告/建议：锁屏、设置、开始菜单里的「建议」、Tips 通知等；
  • 可选：显示文件扩展名、隐藏 3D Objects 等资源管理器小调整。

⚠️ 安全提示

irm | 执行 这种「下载即运行远程代码」的模式，本质是把机器信任交给了那个 URL。虽然 Win11Debloat 是知名开源项目、这行命令也是官方文档给的，但养成习惯：

  1. 先审脚本再跑：浏览器打开 https://debloat.raphi.re/ 或直接看 GitHub 源码，确认内容再执行；也可以先 irm "https://debloat.raphi.re/" | Out-File d.ps1 存下来读一遍再跑；
  2. 先建还原点：Checkpoint-Computer -Description "before debloat" -RestorePointType MODIFY_SETTINGS，出问题能回滚；
  3. 别在生产/别人的机器上盲跑，移除 app 后有些依赖它的功能会消失（如彻底删 Store 后装不了新应用）。

还原

  • 大多数「关闭项」是注册表/组策略改动，重新跑脚本选相反选项、或从还原点回滚即可；
  • 被移除的 app 想装回来：Microsoft Store 搜索重装，或 winget install <id> / Get-AppxPackage -AllUsers <name> | ... 重新注册。
