IP 类型检测工具指南：判断住宅 IP 还是数据中心

快速判断一个 IP 是住宅 ISP 还是数据中心/机房，核心看 ASN 类型、ISP/Org、Usage Type 三个维度。以下从在线工具、命令行/API、商业库三个层面整理。

一、在线工具（最常用，免费）

1. ipinfo.io（首选，ASN 类型最准）

地址：https://ipinfo.io/[IP]

看 3 个关键字段：

字段 住宅 ISP 数据中心
asn.type isp hosting
org 电信/联通/移动/广电等 阿里云/AWS/DO/OVH 等
hostname 运营商域名 含 dc/cloud/server

示例：

2. IP2Location（看 Usage Type，权威）

地址：https://www.ip2location.com/

重点看 Usage Type：

  • ISP/MOB = 住宅/手机
  • DCH = 数据中心

3. IPIPseek（国内友好，中文）

地址：https://www.ipipseek.com/

直接显示 IP 类型（住宅/数据中心/代理）、ISP、风险评分，国内节点查询速度快。

4. ip-api.com（简洁，JSON 接口）

地址：https://ip-api.com/json/[IP]

关键字段：isp、org、as
机房特征：org 含 Hosting/Cloud/Data Center

5. TrustMyIP Cloud IP Check（专检云/机房）

地址：https://trustmyip.com/cloud-ip-check

直接返回：Datacenter/Hosting（是/否）、云厂商（AWS/Azure/GCP 等）

6. Whoer（综合检测，含 DNS 泄露）

地址：https://whoer.com/zh/

看 ASN 与 DNS 服务器：DNS 为运营商 = 住宅；DNS 为云厂商 = 机房

二、命令行/API（适合批量、自动化）

1. curl + ipinfo（Linux/macOS，最常用）

2. bgp.he.net（查 ASN 网段）

地址：https://bgp.he.net/

输入 IP → 看路由：/20~`/24` 大段连续 = 机房；碎片化 = 住宅

3. apnic.net（亚太 IP 注册库）

地址：https://search.apnic.net/

看注册人：运营商分公司 = 住宅；IDC/云公司 = 机房

三、商业/付费工具（高精度、批量）

1. IPQualityScore（IPQS，反爬/风控常用）

地址：https://www.ipqualityscore.com/

输出：住宅/数据中心/代理/VPN、欺诈分、爬虫历史

2. MaxMind GeoIP2（企业级数据库）

字段：isp、organization、user_type

  • residential = 住宅
  • corporate/datacenter = 机房

四、快速判断规则（不用工具也能初步判断）

维度 住宅 ISP 数据中心
ASN 类型 isp hosting（最准）
ISP 名称 国内电信/联通/移动；海外 Comcast/AT&T 阿里云/AWS/DO/DigitalOcean
Usage Type ISP/MOB DCH
反向 DNS 运营商域名 含 dc/cloud/server
网段大小 碎片化 /20~`/24` 大段连续
IP 段归属 运营商分公司 IDC/云公司

五、推荐组合

场景 推荐方案
日常快速查询 ipinfo.io + IP2Location
批量自动化 curl ipinfo.io + bgp.he.net
风控/反爬 IPQualityScore + MaxMind
国内节点 IPIPseek
纯云检测 TrustMyIP Cloud IP Check
