看某接口详情 networkctl status <接口名>
重新应用配置 sudo netplan apply
重连某接口 sudo networkctl reconfigure <接口名>

7. 常见坑

  • 多个 .yaml 文件按文件名字典序加载，同名字段后加载的会覆盖前面的，新建静态 IP 配置时记得处理掉默认的 DHCP 文件。
  • yaml 文件权限要求严格，权限不对（比如全局可读）会静默不生效或报警告，务必 chmod 600。
  • WiFi 配置缺 wpasupplicant 包时，netplan apply 不会报错但连接建立不起来，排查时先确认这个依赖装了。
  • 改错配置导致断网时，物理接屏幕/串口后可以直接编辑 yaml 文件修复，再 netplan apply。
