白嫖 Cloudflare：免费存储（图床/网盘）与监控类开源项目调研

本文最后更新于：2026年11月24日 下午

Cloudflare 的 Workers、Pages、R2、KV、D1、Durable Objects 都有免费额度，社区基于它们做了不少「零成本自托管」的项目。本文把其中两类整理一遍：存储类（图床/网盘）和监控类（可用性拨测 / 服务器探针），并列出各项免费额度，方便评估能不能长期白嫖。

一、存储类（图床 / 网盘）

项目 定位 存储后端 备注
MarSeventh/CloudFlare-ImgBed 图床 / 文件床 / 简易网盘，带管理后台 Telegram Bot、Discord、R2、S3、HuggingFace 功能最全、仍在活跃更新（2026 年 V2.7.x）；支持 WebDAV、API；Pages 与 Docker 两种部署；Telegraph-Image 的重制版
longern/FlareDrive 网盘（WebUI + WebDAV） R2 部署在 Pages；WebDAV 上传受 Workers 限制，≥128MB 文件需走网页分片上传
abersheeran/r2-webdav 纯 WebDAV 服务 R2 FlareDrive 的 WebDAV 部分基于它
yestool/imgUU GitHub 登录的图床 R2 + D1 Astro SSR，MIT；开源版不含 WebP 转换
cmj2002/CF-R2-ImageBed 轻量图床，兼容 PicGo R2 已归档，不建议新部署
yusukebe/r2-image-worker / qwe7002/sliverimage / x-rays5/image-host 极简 Worker 图床 R2（+D1） 适合二次开发

选型建议

  • 想要开箱即用、带后台：CloudFlare-ImgBed。用 Telegram 渠道可以绕开 R2 的 10GB 限制，但稳定性取决于 TG。
  • 想要真正的网盘 / WebDAV 挂载：FlareDrive。

深入一点：CloudFlare-ImgBed 的数据到底存在哪？

数据分成两部分，存放位置不同。

1. 文件本体：存在你配置的「上传渠道」

项目本身不存文件，而是把文件转存到外部渠道：

渠道 实际存放位置 说明
Telegram 你的 TG 频道/群组（Bot 上传） 最常用，空间不限且免费；单文件有大小限制，大文件会分片
Cloudflare R2 你账号下的 R2 存储桶（绑定名 img_r2） 免费 10GB/月，最稳
S3 兼容 你配置的 S3 桶（B2、MinIO、AWS 等）
Discord / HuggingFace 对应平台频道 / 仓库

访问图片时，Worker 先查元数据得知文件在哪个渠道，再去对应渠道拉取并返回。

2. 元数据：存在 Cloudflare KV 或 D1

文件名、渠道 file_id、上传时间、标签、审核状态、黑白名单等元数据存在：

  • KV：命名空间绑定名必须为 img_url。读写快，但免费版写入仅 1000 次/天。
  • D1：绑定名 img_d1（SQLite），免费额度更大。

老版本要求必须配 KV，新版本可在 KV / D1 之间选择，以所用版本的文档为准。

注意

  • 元数据丢了，文件就找不回来了。尤其是 TG 渠道，文件只能靠 file_id 定位，KV/D1 记录丢失后链接全部失效。记得定期在后台导出备份。
  • TG 渠道依赖 Bot 和频道：Bot Token 泄露或频道被删/被封，文件都会丢。
  • Docker 部署时 KV/D1 换成本地存储，元数据在容器挂载的数据目录里，需要持久化。

二、监控类

可用性监控 / 状态页（HTTP / TCP 拨测）

  • lyc8503/UptimeFlare：这一类里的首选。Apache-2.0，10 分钟内可部署，支持自定义域名、密码保护、JSON API。2026 年 1 月存储已从 KV 迁移到 D1，旧教程里的 KV 写法已经过时。
  • ZhangBohan/Uptimer：Workers + D1，用 GitHub Actions 部署。
  • proxy-turkey/pingflare：Workers + D1。
  • cf-workers-status-page：老项目，基于 KV。KV 免费写入只有 1000 次/天，检测频繁会很快超额，不推荐。

服务器探针（CPU / 内存 / 网络，类似哪吒）

  • huilang-me/CF-Server-Monitor：Workers + D1 + Durable Objects，通过 WebSocket 实时推送；7 天历史图表、三网延迟与丢包追踪；Agent 支持 Linux / OpenWrt / 群晖 / Windows / macOS，也有 Docker 镜像。Agent 只单向上报，不提供 WebSSH 和远程命令，比哪吒更安全，但相应少了这些功能。MIT 协议，目前仍是 Beta。

三、Cloudflare 免费额度（决定这些项目能不能长期白嫖）

服务 免费额度
R2 10 GB 存储/月；100 万次 A 类操作（写、列举）；1000 万次 B 类操作（读）；出站流量免费；仅限 Standard 存储
Workers 10 万次请求/天
KV 10 万次读/天，1000 次写/天
D1 单库最大 500MB，账号总计 5GB，最多 10 个库；每次调用最多 50 条查询
Durable Objects 10 万次请求/天；SQLite 存储 5GB

踩坑提醒

  • *.workers.dev 在国内大概率无法访问，务必绑定自己的域名。
  • 超出免费额度后请求会直接报错，不会自动扣费，但服务会中断。
  • 监控类项目要估算「检测频率 × 监控目标数」，看会不会超过 Workers / D1 的每日额度。
  • 文中 star 数与维护状态来自第三方索引，部署前建议到仓库确认最新状态。
