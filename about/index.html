逆向 · 抓包 · 折腾安卓

你好,我是 Ruhai 👋

逆向 · 抓包 · 折腾安卓。 这里记录我在逆向工程、反爬与自动化路上的踩坑与心得,大多是”当时没查到、后来自己趟通”的东西。

平时折腾的方向:

  • 移动端逆向 / 抓包:Android、Frida 解 SSL Pinning(还写了 frida-server-manger 管 frida-server)、mitmproxy / mitmweb、FlowTrans 透明转发、pproxy 海外出口。
  • JS 逆向 / AST:把 astexplorer 做成了 MCP(astexplore-mcp),配合 AST 模板做反混淆与 hook,顺带啃点 V8 / JS 引擎。
  • 反爬 / 反检测:Akamai、TLS / JA3 指纹伪装(curl-impersonate / curl_cffi)、反检测浏览器、Playwright / puppeteer 自动化、滑块验证码。
  • 爬虫工程:cola 爬虫框架 + colad 部署管理平台(agent/master 多节点、实时日志、Web UI,类 scrapyd + crawlab)。
  • AI 工具链:Claude Code、MCP,以及本地模型(MLX / Gemma)辅助逆向与开发。
  • 开发 & 系统:Python / Go / PHP / Vue、FastAPI、macOS、环境配置与 dotfiles。

技术之外,也写一点古典文学(诗词、宋词、古籍)和中医 / 汉方药的笔记——换换脑子。

一些开源项目

  • FlowTrans — 基于 mihomo 的安卓抓包转发器(TUN 透明劫持 → mitmproxy)。
  • android-capture-skill — 一键安卓 HTTPS 抓包:FlowTrans + mitmweb + Frida 脱壳。
  • astexplore-mcp — 把 astexplorer 做成 MCP,解析 JS/TS AST。
  • frida-server-manger — 命令行管理安卓设备上的 frida-server。
  • colad — cola 爬虫框架的部署守护进程 + 管理平台(多节点、Web UI);配套中文文档站 cola-docs。
